# 椅背、冬季外墙与照片色调

父版本：`b08df097c0b1f04a8a37cfb93b199cb5dffdea4a` / `courtyard43-interior16`。
输出：`courtyard43-interior17`，入口缓存 `photo17`。

依据用户 2026-10-02 的椅背标注、窗外雪景和厨房/晾衣照片。照片用于可见关系与色调判断，未引入厨房或晾衣新物件；几何比例仍为照片估计。

## 修正

- 椅背：原上部支撑在白色背板前方，顶部银管形成额外描边。将两侧上段支撑移至背板背面、横管降低并后移；脚底、座面、位置和朝向保持。保留后侧承重构造，新增固定 `chairFront` 网页视角。
- 外墙：复用的矿物纹理实际均值约 `.29 sRGB`，旧乘色却以 `.58` 为基准，导致暗灰绿。保留矿物起伏与独立来源，把底色归一为中性 `.58`，分别校准正面灰粉褐、右侧灰粉、左侧米灰和远处淡黄灰；粗糙度 `.91`，降低均匀自发光。雪、窗框、外景位置均未改变。
- 照片感：仅在 43 号院后处理内降低色彩鲜艳度；微暖集中于中间亮度，保留冷白雪景；恢复暗部对比并轻抬极黑，柔化高光。没有叠加模糊或移动噪点，未改永旺家园后处理。

## 可复现源

在父版本完整源上，经官方 Blender Lab MCP 执行 `../scripts/refine-photo17.py`。脚本保存完整源、独立 winter-exterior 源和同次导出包；不能在已经完成的 interior17 上重复执行。

外墙新底纹 `../assets/winter-exterior/textures/photo17-neutral-mineral.png` 从已隔离的永旺 handles39 矿物纹理生成，保留原起伏来源，不回写永旺。网页颜色变换在 `room-site/dist/courtyard43-effects.js`。
