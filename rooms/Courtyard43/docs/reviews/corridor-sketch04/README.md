# 饭桌区与厨房分隔：修正版 04

根据用户新标注恢复走廊右侧墙段，把原先笼统的“厨房”分成饭桌区和厨房，之间设双扇推拉门。两扇门在图上方半段重叠，图下方半段通行；半开状态为用户确认，具体向哪一侧收拢仍为示意。饭桌区最上方增加用户标记的房门，不擅自命名为入户门。走廊保持空置，两侧次卧只保留关闭且不可探索的门。

重新查看 V02 10.80–17.90 秒：饭桌靠墙，有白椅、纸张和靠墙木板；进入厨房后正面为双槽水池，其左侧为窗下上开盖洗衣机，右侧为微波炉，再经台面转角到双眼燃气灶；上方可见吊柜、热水器、油烟机和烟管。图中依此相对关系摆放，替换此前未经细核的示意台面。厨卫精确尺寸、门洞偏移、物体型号和不可见细节仍不作实测声明。
