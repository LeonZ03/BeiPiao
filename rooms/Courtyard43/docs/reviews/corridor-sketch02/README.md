# 门外布局：按用户手绘修正版 02

用户在 2026-09-30 提供手绘，明确走廊两侧为次卧，只做两扇关闭的门，不可打开、不可探索。原 `corridor-hypothesis01` 的折转过道和厨卫方位假设已被本图取代。

图面朝向与手绘一致，不表示地理方向：下方为卧室，门在靠左位置，出门进入横向走廊；上方左侧厕所、右侧厨房；走廊左右两端分别保留一扇次卧关闭门。次卧未建任何内部空间，也没有开门交互。

尺寸、门洞精确偏移、门扇开向仍为图示估计。结合 V02 放入厕所的马桶与立柱盆、厨房的水槽与转角台面/洗衣机、门外桌椅帮助辨认；这些设施的精确位置尚未由手绘确定。卧室仅画示意范围，不替换既有获认可室内布局。
