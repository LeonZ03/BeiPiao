## 源、复用与复现

完整源：`assets/full-room/Courtyard43-interior.blend`；独立可打开组件：`assets/development-kit/Courtyard43-development-kit.blend`，含 10 个可编辑网格及独立材质、3 张微表面贴图。现有房间没有对应开发板，因此新建；沿用既有圆角实体、管状线缆和 PBR 导出方法，不重新导入或改写永旺资产。

所有建模、材质、源检查和导出通过官方 Blender Lab MCP 执行，顺序：

1. `add-desktop-kit.py`：断言 interior12，创建初版组装，保存 interior13。
2. `refine-desktop-kit.py`：断言未精修的 interior13，补丝印、贴片和微表面贴图。
3. `fit-desktop-kit.py`：断言尚未配合修正，分离小板与 USB 接口，补圆边旋钮和角度各异的一字槽。
4. 在新的 MCP 后台进程打开完整源运行 `save-desktop-kit-source.py`，仅将已保存组件输出到独立源，不能把裁剪后的场景另存回完整源。
5. 重新打开完整源运行 `export-interior.py`，网页包与源对应，缓存为 `desktop13 / courtyard43-interior13`。

Blender 5.2.2 的 partial-library writer 对新建 Scene 出现过 `BKE_view_layer_copy_data` 崩溃。完整源已先保存；恢复后使用新的后台进程裁剪并正常保存组件，重新打开确认。不要使用该 Scene 部分写出方式。
