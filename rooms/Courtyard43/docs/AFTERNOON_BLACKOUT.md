# 43号院 · 下午雪景与遮光帘（interior11）

用户要求窗外持续飘雪；首次开帘、关门、关灯；下午室内略亮；灰帘厚实、哑光、遮光，合上不留亮缝。尺寸仍是已批准布局上的照片估计。

父提交为 `9ec1f6f37385ac0d5039ed5996953111dbfa523d`（interior10）。官方 Blender Lab MCP 执行 `refine-blackout-curtains.py` → `refine-blackout-shell.py` → `refine-blackout-overlap.py`，保存完整源、独立 `assets/blackout-curtains/Courtyard43-blackout-curtains.blend` 和同次导出包。各脚本有父 revision 或防重复标记，不得再次套用到成品。复用本房间现有灰帘拓扑、纹理与形态键，网格和材质独立复制。

布体约 2.9 mm 厚，缝边更厚；粗糙度 0.94，低反光，无透光发光图。两侧各覆盖窗洞边界约 30 mm，并回包到墙面；中缝搭接约 20 mm，两扇帘边在深度上分开。较宽的初稿搭接会碰台面、在中间状态互穿，已按实际承托和运动检查收窄并错层。顶部保持挂环连接，下摆原有支承间隙不变。

两个窗帘描述符 `defaultOpen:true`，门轴源为关闭姿态且 `defaultOpen:false`。首次渲染前应用全部初始状态并校准光照；顶灯和声音仍默认关闭。同页面退出重入保留用户操作，刷新才重新初始化。

北向冬季散射光保持方向、色温与单顶灯结构，适度提高开帘环境光和室内反射。闭帘显著变暗，取消布面透光。没有增加直射太阳或一圈灯。

雪粒子为 900 个固定种子 GPU 点，近处稍密、远处稍疏；沿重力缓慢下落并有轻微横摆。开帘且朝窗时从室内即可看见，进入阳台后不受室内闭帘遮挡条件限制。深度遮挡保持，雪不进入房间；闭帘室内、总览、首页、后台、减少动态效果时暂停。静止雪景沿用约 42 ms 重绘节奏，不在 CPU 逐帧改网格；尚未采用永旺的 HDR 静态缓存。
