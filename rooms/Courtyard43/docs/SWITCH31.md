# 封闭开关壳体与细步长升降

父提交 `724d170`，父模型 `courtyard43-mirror29a` / `props45`。两房均经官方 Blender Lab MCP 修改、保存完整源和同次导出，输出 `courtyard43-switch31` / `props46`，网页缓存 `switch31`。

旧深色缝隙盒的正面与白底座正面共面，引起斜视移动闪烁。永旺底座背面还距内墙约5毫米，使侧看产生悬空、中空观感。原来的三个独立盒子虽然各自闭合，组合关系仍不正确。

本版在43号院一次制作带封闭背板、连续侧壁和浅凹槽底面的整体壳体；翘板有封闭的后侧裙边。停用共面的深色缝隙盒，底座背部嵌入墙面约0.5毫米，保留窄装配缝。永旺从该完整源追加两个最终网格和材质，独立复制后定位，不再重复建第二套几何。86毫米外形及内部装配均为普通无品牌开关的合理估计。

开关最大转角从旧0.10–0.13弧度减至0.045弧度，源交互与网页一致。源网格检查全部边为流形、体积为正；导出测试焊接同位置顶点后，每条边恰有两个相邻三角面。射线验证装配缝后有实体凹槽底面，并采样21个按动状态检查翘板与底、侧壁间距。

滚轮升降比例由0.0015减至0.0005米/像素，100像素滚动量对应约5厘米，单事件上限6厘米；保留触控板的小增量。空间总览仍由OrbitControls原有缩放处理。

定向验收为 `tests/rackets-switches.mjs`、`tests/input-mirror.mjs`、JS/Python静态检查及Pages包一致性。网页检查两房开关正面与斜侧近景、实际前后移动和环顾、灯光开关往返，以及细步长升降；截图保存在本地忽略目录 `analysis/switch31/`。

网页实测：两房实际点击灯光往返均通过，按动后移动及大斜角侧看无旧共面深色面闪烁；43号院控制台未见警告/错误。相同0.15页滚轮输入，永旺入口高度由1.560升至1.614米，位移5.4厘米（旧版16.2厘米），X/Z不变。压缩包相对父版本仅增加永旺约33KB、43号院约28KB。
