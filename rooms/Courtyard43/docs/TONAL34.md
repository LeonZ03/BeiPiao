# tonal34：减少惨白与均匀填光

父提交 `8415226`，模型保持 `courtyard43-switch32`。用户反馈画面惨白、对比不足；本轮只调整43号院的实时照明与最后一道调色，不重建模型或贴图，不改变永旺家园的照明。

## 原因与调整

daylight28 为改善灰暗感，同时提高了环境反射、半球光和室内反弹光。它们叠加后使各朝向表面过于接近，床褶、柜门侧面、桌下和灰帘褶谷缺少层次；后期对比为1，另有少量阴影抬升。这是本轮处理的显示问题，不能代替后续实际形体精修。

曝光仍为1.18，保持线性光照、单次ACES与sRGB输出。开帘时环境强度0.57→0.41、半球光0.65→0.50、室内反弹0.63→0.44；北窗方向性光0.405→0.925，保持原方向与位置，阴影强度降至0.66以保留漫射感。每侧窗边补光1.385→1.485。雪地反射从全屋均匀抬亮改为更集中于窗侧的光源关系；未添加直射太阳、光斑、雾或更多灰尘。

北窗主光改为接近中性的白色，保留略冷的天空光和温暖的室内反弹。后期对比1→1.09、饱和度0.97→0.99；中间调微暖，移除额外暗部抬升，高光不加黄。没有增加AO强度或使用锐化描边。

所有参数集中在 `courtyard43-look.js`。光源仍为6个，投影光源仍为2个；分辨率、采样数、模型、材质与粒子数量不变，无额外全屏处理步骤。入口及依赖缓存更新至tonal34；永旺模块仍使用contact33。

## 验收范围

固定入口、床边、桌面、灰帘网页机位，检查开闭帘和开关顶灯四种组合；另检查无调色状态、移动转向及390×844手机视口模拟。截图与临时记录位于本地忽略目录 `analysis/tonal34/`。执行相关光照检查、改动模块语法检查及Pages资源打包检查；本轮没有几何变更，不重跑建模、床品组合或全站几何回归。

网页画面评价仍有主观性。本轮不宣称修复了所有建模质感问题，也不以截图亮度统计代替视觉验收；未做真实手机硬件性能测试。
