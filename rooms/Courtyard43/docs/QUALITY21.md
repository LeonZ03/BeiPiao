## 固定比较条件

本地 HTTP 网页，桌面 1280×720，入口、床边、桌面、灰帘四组主视角，椅子、柜台、地板补充近景。基准为开帘、关门、关灯、静音；相机使用网页既有命名机位。临时图像及相机/性能数据保存在忽略目录 `analysis/Courtyard43/quality21/`。

基准三次入口转动采样，平均帧间隔中位值 58.88 ms，P90 中位值 66.8 ms。这里只适用于本次相同设备、视口及负载，不能与历史不同条件的 31.1 ms 横向比较。基准包 667,968 三角面，压缩二进制 9,890,838 字节。

验收 WebMCP `set_courtyard43_review_look` 提供 `neutral-grey`、`no-grade`、`final`，不增加用户界面、不持久化状态。灰材质保留透明物的遮挡，统一检查实体轮廓；关闭调色时保留相同灯光和接触阴影。

## 主要材料比较基准

| 表面 | 应有区别 | 当前主要问题与处理方向 |
| --- | --- | --- |
| 墙面与顶面 | 中性偏暖、散射为主，细微表面变化 | 避免高强度均匀填光和高对比噪声 |
| 床单、花被、枕套 | 漫反射棉织物，压边与蓬松部分明暗连续 | 先重建承托和蓬松体，再校微反射 |
| 衣柜白门 | 略暖饰面板，边缘较利落，反光宽且弱 | 不与墙漆共用同样的粗糙度观感 |
| 白椅背 | 模塑壳体，弧面和包边上有柔和高光 | 保留白色上沿，金属支撑在背面 |
| 灰帘 | 厚哑光遮光布，柔和宽反射 | 不用归零反射代替布料；无格状闪光 |
| 黑坐垫 | 很深的织物，边缘可辨认，压座处较薄 | 不黑成剪影、不再是硬方板 |

所有基础色按 sRGB 解码，法线/粗糙度/AO 为线性数据；保留线性 HDR、ACES、sRGB 输出。Blender 预览不是网页调色的验收替代品。
