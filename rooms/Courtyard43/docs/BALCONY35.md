## 制作与复用

从当前完整源增量修改，脚本 `scripts/refine-balcony35.py` 经官方 Blender Lab MCP 执行。保留现有墙面材质、所有室内家具、灰色遮光帘和交互。阳台柜与当前卧室高衣柜的尺寸、结构和旧化程度不同，因此单独建模，不缩放旧衣柜凑形。晾衣杆采用简单刚性杆件，旧外帘不带入室内遮光帘的形态键或风动。

仅替换两组旧实心边顶对象；578 个无关源对象及原有材料摘要保持一致。新物件保留 UV/UV1、实际板厚、倒角与封闭表面；旧帘为实体薄壳。原完整工程与同次导出三文件一并保存。永旺家园源、模型包及专用运行文件不改动。

增加四个诊断机位 `balconyLeft`、`balconyRight`、`dryingRack`、`bedheadCeiling`，正式 UI 不增加按钮。
