# 室内微尘与照片椅子

父提交：`a4171a9e594c52a1879e75789b747ab66a3fcd0b`，父场景 `courtyard43-interior17`。
输出：`courtyard43-interior18`，入口缓存 `atmosphere18`。

## 实现依据

用户希望有冬天老房子久未住人的空气感，并补充椅子近照。尘埃保持稀疏、缓慢和克制，不新增浓雾、光束或满屏噪点。椅子按可见轮廓估计比例，不宣称实测 1:1。

- 椅子：宽而浅的弧形白靠背、白色卷边、后侧弯曲细管、薄黑坐垫及两侧白色系带。修复正面钢管露成三角的交叉，保留原位置及朝向。
- 源：从父版本经官方 Blender Lab MCP 执行 `../scripts/refine-chair18.py`，同时保存完整源及网页模型包。保留 `C43_Chair15_*` 名称与既有交互约定；526 个非目标对象摘要不变，永旺源哈希不变。完整源是本轮权威，不能用旧家具组件覆盖。
- 微尘：独立 `courtyard43-dust.js`，128 个固定种子粒子分布于室内空气体积。GPU 有界慢漂移、不持续下落；物理尺寸约 2–4 mm，投影限制约 0.9–2.3 CSS 像素。普通透明混合与深度测试让家具、墙和屏风正确遮挡。
- 光照：靠北窗较明显，向室内逐渐衰减；左右帘分别控制各侧亮度，开顶灯稍增加可见度。闭帘关灯时保持很淡，沿用原冬季色调。
- 性能：微尘只增加一个绘制批次，无逐帧 CPU 几何写入；与飘雪共用约 24 次/秒重绘节奏。首页、后台、总览和系统减少动态效果时暂停，恢复时限制时间步长。

- 官方 MCP 重开完整源为 interior18，无缺失图片。456 网格、667,968 三角形、33 贴图；原始包 29,475,392 字节，相比父版本增加约 0.9%。
- 椅背 15 条正面射线首先命中白色靠背；场景几何、接触、PBR、UV/UV1、形态键、压缩一致性与既有门帘检查通过。
- 微尘范围、深度设置、固定缓冲、暂停与销毁检查通过；运行时、会话返回、旧房间边界及 Pages 分块检查通过。
- 桌面实看椅子正反面、窗边静看微尘缓慢位移，并闭合/打开窗帘检查亮度。闭帘视角 5.5 秒转动平均帧间隔 21.9 ms，P90 33.4 ms，仅代表本设备与该视角。
- 手机尺寸采用桌面浏览器 390×844 及 844×390 模拟，不代表真实手机硬件性能。
- 手机横竖屏控件、横移和首页退出/重入通过；退出时微尘、雪与音频均暂停，状态保留。未观察到新增资源或着色器错误；控制台仍记录既有无来源 MutationObserver/Node 错误。
