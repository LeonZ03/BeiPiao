# 北向雪地反光与普通开关

从 `charger27a / winter27` 调整到模型 `switch28`、光照 `daylight28`。已确认布局、窗外位置、微尘、雪量和默认开帘/关门/关灯/静音保持。

此前偏灰的原因：主要增加了暖调，开帘时的环境照度仍不足；半球光下半部固定偏暗棕色，同时降饱和、对比和暗角进一步压低观感。本轮加强开帘后的宽泛雪地反光及室内反弹光，下半球随开帘由暗木色过渡到较亮中性色。仍只有原六个光源、两个投影光源，不增加直射太阳和假光斑。

曝光1.18、线性光照、ACES和sRGB输出保持；饱和度0.91→0.97、对比1.04→1.00，减弱黄褐中间调、暗角和高光扣减。雪景保留冷白，室内略暖且明亮。GLSL数值统一输出浮点字面量，避免整数参数导致着色器编译失败。

固定1280×720网页机位：入口、床边、桌面、窗外正看；另检查闭帘关灯、闭帘开灯及开帘开灯。前后截图保存在本地忽略的 `analysis/Courtyard43/daylight28/`。此处是网页截图，不是Blender渲染。执行 `tests/courtyard43-lighting.mjs`，覆盖光源预算、独立双帘、开灯响应与环境释放。

普通开关由 `scripts/refine-switch28.py` 经官方Blender Lab MCP制作，使用与永旺相同的通用薄面框大翘板外观；网格和材质独立，保留原点击/动画接口，其余源对象摘要一致。来源和限制见[球拍与开关记录](../../yongwang-jiayuan/docs/RACKETS44.md)。

最终已实看390×844竖屏及844×390横屏，并恢复浏览器原视口；这是尺寸模拟，不是真机性能测试。两房均实际点击开关往返，默认关灯恢复；最终页面检查无新增资源、WebGL或着色器错误。定向光照、几何及Pages资源检查通过；本轮未改动画数量或执行跨设备帧率比较。
