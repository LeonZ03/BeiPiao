# interior15：灰帘、椅子与日常物件修正

父提交 `dd09f3965c7951feb037a3bd33d5079b88bce6ab`，父场景 `courtyard43-interior14`。本轮以入住后 P03/P04、已有椅子近照及用户本轮七项说明为证据；位置沿用已批准布局。椅子、包装袋、瓶体和插座的尺寸及未见侧面仍为照片估计，不称测量级 1:1。

当前权威源为 `../assets/full-room/Courtyard43-interior.blend`，revision `courtyard43-interior15`。历史 architecture08 / furniture06 / props02 组件不含本轮修改，不可用这些旧组件重新组装覆盖当前完整源。

## 修改范围

- 灰帘保留双层实体和独立形态键；侧边、下摆局部加厚，增加轻微不规则宽褶。纹理改为低对比正方形织纹，按米制 UV 校准。消除强格纹、sheen 和高光条带：roughness 1、metalness 0、sheen 0、specularIntensity .006、envMapIntensity .025、normalScale .009。仍是不透明遮光布，闭合搭接和固定点保留。
- 左侧棒球帽追加永旺 `handles39` 完整场景的 `Black LA Baseball Cap` 及帽冠、帽檐、缝线、LA 绣字完整层级，独立复制网格与材质。源路径、revision、SHA256 保存在新根对象 `reuse` 属性及场景 `details15` 记录中。未回写永旺。右侧改为软冠、下垂环形帽檐的渔夫帽；另一个较小圆形墙饰保持。
- 椅子按实物重建薄黑坐垫、弯曲白色靠背、连续金属管后腿/靠背支撑、前腿、横撑、脚套和坐垫绑带。原 `C43_DeskChair` 根和摆放锚点保持。
- 花被整体收回床垫上，缝边随同调整；白床单垂边缩短。被子最低点约 .572 m，白床单最低点约 .463 m，均为模型检查值。
- 挂物按塑料垃圾袋包装重做收口、侧褶及蓝白分色，蓝色露出物改为斜向伸出的圆柱卷，端面可见卷层。照片无法辨认的包装文字留空。
- 台上水瓶按用户确认改为农夫山泉大瓶轮廓、红盖、防拆圈、环肋与红白标识。水位按模型内部体积的 75% 计算；没有推定容量、配料或条码。水体使用有限透明网格，不做昂贵实时折射。
- 插座恢复横向白色多位面板和两孔/斜三孔结构。电源线连续经过插头、桌边、适配器、电脑接口，并有两端护套；粗细与弯曲为参考估计。

## 官方 MCP 复现顺序

从上述父版本完整源运行 `refine-details15.py`（内部调用 `refine-chair15.py`、`refine-curtains15.py`），再运行 `fit-details15.py`、`finish-details15.py`，最后调用 `export-interior.py` 的 `export_interior()`。全部通过 Blender Lab 官方 MCP；不要直接运行 Blender 可执行文件或旧完整生成器。断言用于防止重复覆盖。

`fit` 修正闭合物件外向法线、焊接线缆端面并限制水体细分；`finish` 保留瓶身文字沿曲面包覆时的挤出厚度，避免退化三角面。低对比灰帘贴图保存在建筑贴图目录，不依赖临时报告。

- 完整源重开无缺图；九个重点实体均闭合、正体积、无零面积面。四组床品/床垫 BVH 交叉为零。
