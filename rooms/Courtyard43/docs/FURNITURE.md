# Courtyard43 家具组件

组件源：`assets/furniture/Courtyard43-furniture.blend`；独立生成脚本：`scripts/build-furniture.py`；只读检查/可选检查渲染：`scripts/furniture-check.py`。全部建模、材料生成、源检查及渲染均经 Blender Lab 官方 MCP 后台执行。根集合为 `C43_Furniture`，当前组件版本 `courtyard43-furniture02`。主工程及网页由整合脚本另行创建，不覆盖白模。

## 依据与边界

以入住后 P03/P04 为外观主参考，空房 P01 补白板床头、细圆腿与桌架。用户已经认可的 `whitebox06`（`cb6fe56615a53e26810968f6c704c7536ffeba1a`）及 `history/inputs/approved-layout.json` 锁定了大件布局。床长 2.4 米、宽 1.5 米及其他尺寸仍然属于照片比例估计，并非实测。

床平台网页包围盒为 X `[-1.965, 0.435]`、Y `[0.370, 0.415]`、Z `[1.280, 2.780]`；床头保持 X `[-1.990, -1.930]`、顶高 1.110。桌面保持 X `[-2.000, -0.700]`、Z `[0.030, 0.580]`、顶高 0.740。衣柜柜体保持 X `[1.675, 2.225]`、Z `[0.225, 1.375]`、顶高 2.050。床品的有限垂边属于软物细化，没有移动床架边界。只保留一把桌前白背黑座金属椅，椅背朝床，入口没有备用椅。

## 复用及隔离

只读来源为永旺家园最终完整源 `rooms/yongwang-jiayuan/assets/full-room/永旺家园-完整场景.blend`，`web_revision=sunview34`，SHA-256：`67765fb8a97bf6b86d9d272f5319ab8aa047f5330438210ccce063a06833e150`。来源在上述父提交与本轮之后均未修改；构建前后强制核对 hash。

- `full-cotton-pillow` 及 `pillow-piped-seam`：复制最终求值网格，保持原曲面比例，平面转向 90°后移至床头。仅在独立副本焊接 1 微米范围的重合缝端点并统一法线，没有拉伸旧枕头，也没有回写源。
- `duvet-top` 的 `Material 084`：先沿 active Material Output 找到真正连接的 Principled（不是同材质里遗留的未连接节点），确认浅底玫瑰纹与本房照片一致。复制 `quilt-flat-floral-v2.png` 与棉纱凹凸图。新被子按此房床长新建连续曲面，不能拉伸旧几何凑比例。
- `full-cotton-pillow` 的 `Material 086`：独立复制 `woven-cloth.jpg` 与 `cotton-thread-relief.png`，用于素棉枕和床单。
- 新建家具材质为直连 Principled 的独立贴图或参数；枫木色图和粗糙度图由 MCP 中的确定性脚本生成，没有烘入场景明暗。颜色为 sRGB，粗糙度和棉纱高度为 Non-Color。棉布基础色使用 UV0，棉纱使用单独 UV1。

第二轮根据 P03 与真实网页核对，将枫木改为低饱和浅米色：目标 PNG 平均 sRGB 为 `#D4C7B2`（212、199、178），边带为同系 `#D0C1A7`。由 MCP 直接编码目标 PNG 字节，基础色不经过含糊的 Blender 浮点像素保存转换；边带常量只做一次 sRGB 到线性解码。颜色图读回均值约 `[212.13, 199.11, 178.10]`，范围 `[209..215,197..201,176..180]`；纵向木纤维为不规则弱纹理，避免明显橙褐色和等距条带。粗糙度约 0.58、变化约 0.012。

花纹图像沿用原独立副本，UV0 重复乘 `1/0.78`，使印花线性尺寸比首版缩小 22%；不缩放几何，棉纱 UV1 密度保持不变。被面保留三条有方向的宽缓斜褶，增强低幅起伏、两处局部堆积及不等高垂边，避免密集随机褶皱。

图像均实际复制到组件 `textures/`，保存相对路径；没有 Blender Library、跨房间可写网格或材质链接。逐图来源与 hash 记录于 `assets/furniture/provenance.json`。沿用原资产的项目内来源记录，未引入第三方下载素材。

## 几何与交互

床使用白色实体板床头、枫木边带平台、白漆细圆腿及黑色脚套。床垫是圆角实体并保留细管状包边。白床单为约 1.8 毫米闭合连续布层，花纹棉被为约 7 毫米闭合布层，宽缓斜褶和床沿圆弧下落连续。枕头底部与床单的最低间隙约 0.3 毫米，床垫底面与平台顶面同为 0.415 米；床品不会穿床垫。

书桌为 3 厘米实体木纹面板、白细方管腿、侧撑及脚套。单椅为黑色圆角软座、约 5 毫米有厚度的浅凹白背板、金属腿和背架。床/桌/椅脚套最低点均为地面 0。真实板厚、圆管、边带、接合和局部倒角承担近景轮廓，没有无厚度家具平面。

衣柜采用木色侧板、白色双门、独立把手和金属铰链；柜内仅合理补全为空柜、一块高层板和挂杆，**柜内结构属于推定**，没有编造衣物、镜子或装饰品。柜门后沿与柜体保留约 3 毫米构造间隙。

| `C43_WardrobeDoorFarPivot` | `wardrobeFar` | `y` | `-1.2566370614` 弧度（-72°） | 靠阳台一门，限制开度以避让暖气罩台面 |

## 验收记录

当前 96 个对象、90 个网格、122,692 个三角面，约 61,516 个顶点。重新打开源检查：所有坐标与 UV 有限、纹理可解析、无外部 Library；所有网格无非流形边、负有向体积或退化面。旧源 hash 不变。

第二轮前后对全部 88 个非目标网格的求值后世界坐标作 hash 比较，完全一致；几何变化仅为花纹被面和其缝边。所有床、桌、椅、柜及素床单/枕头边界和接触面保持。

床单/床垫、棉被/床垫、枕头/床垫、棉被/枕头及棉被/床单的 BVH 三角交叉均为 0。柜门同时在 25 个开合样本检查，门板与柜体、彼此、暖气罩/台面及灰帘包络无交叉；暖气台面额外扩大 20 毫米后仍无交叉，门板中间高度采样最小间距约 27.6 毫米。此为几何采样结果，不是实际测量精度承诺。

中性照明离线检查图和详细报告位于忽略的 `analysis/Courtyard43/furniture/`，只作几何和材质辅助；最终观感、点击开合、遮挡、碰撞与实时照明仍需主智能体在网页整合后验收。
