# 表面贴合、共用开关与牙刷（props45）

父版本 `ce9e183 / props44a`，经官方 Blender Lab MCP 执行 `scripts/refine-surface-props45.py`，保存完整源与同次三件网页包。房间布局、家具锚点、灯光、笔记本及其他既有资产保持。

- 两拍正面截面宽度从约21.6mm收窄到14.8mm；这是照片估计，区别于厂商标注的前后梁厚。保持内框、拍线端点及挂点。护框和线孔外端跟随外轮廓。
- Wilson、HEAD及拍框文字按曲面投射，细分字标网格，使标识附着而非跨越空腔。曲面上方40μm加polygon offset避免近共面闪烁；保留既有可辨认品牌图案，不新增未确认型号。
- 开关直接从43号院 `switch28` 完整源追加面框、翘板、底缝网格及材料，独立复制后保留永旺位置、点击和灯光动作。
- 上版差异原因：两套脚本分别制作了相似开关，永旺又在更新位置后、依赖图刷新前读取导出矩阵，清单保留了旧的翘板X=1.372，较源里的1.387多突出15mm。本版导出前刷新依赖图，并检查实际位置；不再把“外观规格相同”当成已经复用。
- 牙刷保留桌面锚点，重建圆润白柄、接环、连续刷颈和椭圆刷头，刷毛根部嵌入曲面；不再沿用错位的独立矩形刷头和旧毛束。具体细部为照片估计，未假定品牌。

定向验收：`tests/rackets-switches.mjs` 覆盖32个目标网格、法线/索引/压缩一致性、共用开关大小和底色、源/导出翘板位置及旧刷毛停用。`tests/input-mirror.mjs`、`tests/wardrobe.mjs` 覆盖共用输入与镜面契约。网页按球拍正面/侧面、牙刷和开关近景检查，实际点击开关及升降；未运行与这些局部修改无关的整套历史回归。
