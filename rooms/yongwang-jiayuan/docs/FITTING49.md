# 门叶接缝、顶灯接顶及排插孔型 · fitting49

父提交 `b878cf9`，`doorframe48 → fitting49`。全部模型修改经官方 Blender Lab MCP 保存源工程和导出包。

- 门套外轮廓保持 doorframe48。原先只修改门套，没有校准固定门叶整组的深度，也缺少两侧止口。现将 `entrance-door` 整组向框内移动约20毫米、沿门宽方向校准5毫米，连同铰链、执手、反锁和门饰一起移动；上止口同步，补两侧实心木止口，留约2毫米背面间隙。门套内侧边条同时覆盖裸露的浅色墙体返边，避免斜看仍见亮边。使用实际几何挡住边缝，未用黑色平面或降低灯光遮掩。新增侧止口挂在既有门套节点下，沿用总览显隐，refs保持一致。
- 主顶灯底座原来距实际天花下表面约55毫米。底座和灯罩共同上移55毫米，形态保持；运行时柔光填充中心从当前灯罩包围盒推导，保留约20厘米的等效偏移，使接顶后的天花照度保持接近原来，避免点光源过近形成刺眼光斑。浴室灯已贴住其吊顶，不移动。
- 排插外壳、三位数量、黑插头和现有线路保留。孔型参考[公牛GN-109K官方实物图](https://www.gongniu.cn/show-24-1247-1.html)：三条直孔对齐、下方两斜孔方向相对；只用于校准可见孔型，现有排插型号未确认。重做三个面板，向下切入底壳形成盲孔腔，安全挡片退到孔内，保留孔间塑料；黑插头两根插脚进入对应孔位。孔位尺寸按实物图比例估计，未复制产品商标或照片贴图。

新增诊断机位 `ceilingLamp`、`powerStrip`，正式UI不增加按钮。`tests/room-fittings.mjs` 检查真实网页包的灯座接顶、14条门缝射线被止口阻挡、6条斜视射线命中木质收口、15个插孔首先命中凹入挡片及压缩一致性；源工程检查目标网格封闭且无缺图。网页另查近景、移动和开关灯，Pages检查发布分片一致性。
