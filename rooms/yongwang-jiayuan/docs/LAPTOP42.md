# 笔记本标志、供电线和鼠标垫修正

父提交 `d567a54`，永旺从 `inspiron41` 经 `laptop42` 到 `laptop42b`；43号院从 `courtyard43-laptop25` 到 `courtyard43-logo26`。

- 两房盖外字标修正为从外侧正确阅读的 DELL。旧版只镜像单字而未镜像字间位置，造成 LLED；本版在统一平面构造粗体轮廓后转换到盖外侧。保留原盖、转轴、位置及开合。
- 永旺移除白色 USB 充电器及右侧 USB 接头，改成黑色电源砖、排插输入线、左后侧 DC 圆口接头和输出线。线从转轴后及左侧绕行，输出线网格逐点核对机身运动范围，电源砖落在桌面。适配器尺寸、余线为视觉估计，未添加不可确认铭牌。
- 永旺复用43号院当前完整源 `C43_DevKit_Mousemat`，430×280×2 mm 产品尺寸、原图案、哑光材质、UV0/UV1均保留。保留永旺鼠标垫中心及鼠标位置，随电脑朝向旋转，独立网格/材质/图像；43号院鼠标垫源未改。
- 修复静态合批重新显示已隐藏无名旧零件的问题；碰撞也忽略隐藏对象。否则被隐藏的旧 USB 接头仍会穿进新黑色插头。

脚本 `refine-laptop42.py`、`reuse-mousemat42b.py`、43号院 `refine-logo26.py` 均有父版本断言，通过官方 Blender Lab MCP 执行。源和导出物同步保存。仅进行笔记本/供电/鼠标垫近景及开合定向检查、两包一致性和Pages打包核对，不运行无关整房回归。
