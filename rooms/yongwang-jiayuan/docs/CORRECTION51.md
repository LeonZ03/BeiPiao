# 被否决造型的逐件修正

基线提交 `1075201`，`finish50e → correction51 → correction51b → correction51c`。上一轮圆顶高达、帽檐折角、瓶身形状、椅底露角及过小尾翼均被用户明确否决；FINISH50是历史过程，不再作为已认可造型。所有源修改、检查及导出通过官方 Blender Lab MCP，本轮不使用子智能体。

- 高达：原始头部近照未在现有参考中找到。用户随后授权“上网找个经典点的，就改头”。采用[万代官方 RG RX-178 Mk-II](https://www.bandaispirits.co.jp/products/search/detail.php?grp_id=5325&prd_id=4543112763198000)正面/背面产品图校准白色头壳。恢复正侧装甲平面、倒角截面、上收斜面和平顶，避免椭圆球顶。精确映射原补片224个顶点，断言其余身体顶点不变；眉眼、面罩、传感器和V形天线保留。此项为经用户授权的经典造型替代，不冒称用户原物复刻。
- 棒球帽：旧变形以膨出的X坐标反求asin并截断，造成帽檐侧根扭折，缝线也跟着折起。本轮直接从统一连续曲面制作实体帽檐和六道细缝线，保持约7厘米前伸、2.8毫米实体厚度及克制横向弯曲；不改变帽冠、LA标识、根位置、挂点和材质。两房使用同一纯几何函数、各自独立网格。
- 瓶子：用用户提供的飘柔170g、舒肤佳200g、LUX正面图校准轮廓宽高。原先线性少截面、偏窄宽度、细长颈部造成细瘦和肩部折线；现为单调三次插值的连续肩腰曲线，扩大舒肤佳/LUX的正面宽度，重做蓝翻盖、加宽LUX泵颈和出嘴。标签依附同一曲面，保留正确文字方向及原图。瓶底仍接实际层板，盖与瓶肩实接。绝对尺寸和侧面深度为估计。
- 椅子：不是继续加粗椅背盖住问题，而是将原下座垫后部两角收进椅壳范围；原软包、座面、木腿、位置和朝向不变。
- 头盔：原尾翼收缩系数0.48过小，重新由原坐标计算为0.76，竖向压低从30毫米减为12毫米，主体、标识、镜片和落点不动。尺寸由现有实拍侧面关系估计。

源码：`cap-bill51.py`为无场景副作用的跨房间曲面函数；`refine-correction51.py`处理五类返修中的帽檐、椅角、尾翼、瓶型；`refine-head51.py`只改头壳；`refine-product-fit51.py`校准最终正面比例。不得重跑旧整房生成器。保留父版本断言，正式输入不依赖临时图片。

导出尽量复用目标自身缓冲容量，仅增长的瓶体追加范围；旧描述符不被改写、其他活动节点不共用被覆盖范围。raw为104,538,016字节，低于100MiB限制；最终两步未再次增加体积。
