## 运行

从本目录运行 `python -m http.server 8765 --bind 127.0.0.1 --directory dist`，浏览器访问显示的本地地址。

- 拖动画面环顾，WASD / 方向键行走；双击进入鼠标锁定，Esc 退出。
- 按住 Shift 上升、Ctrl 下降（左右两侧按键均支持），限于地面与天花板之间；Shift 不再加速。
- 手机使用屏幕方向键移动、“升 / 降”改变高度，拖动环顾。
- 切换空间总览后拖动旋转、滚轮缩放。
- 点击实际开关开关顶灯，点击纱帘开合，点击喷头或混水阀控制花洒，点击水龙头控制盆内水柱；屏幕按钮与场景状态同步。

源码：`dist/main.js` 是房间主体与交互，`dist/details.js` 是生活物品，`dist/precision-models.js` 是近看细节，`dist/room-layout.js` 是隔墙与通行边界，`dist/bathroom.js` 是卫生间，`dist/exterior.js` 是窗外简化场景，`dist/afternoon.js` 是午后光照，`dist/wardrobe-assets.js` 与 `dist/gsx250r.js` 是参照用户照片制作的实时模型。本轮在本机 Blender 5.2.1 LTS 中制作床品、椅子软包、树枝与叶片，并导出实际网格给网页使用。Blender Cycles 以 128 采样烘焙房间的漫反射间接光，实时阳光、反射和交互仍由 Three.js 绘制。离线生成图不等同于网页截图。
Three.js 0.180.0 的许可证在 `dist/vendor/LICENSE`。
